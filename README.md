# garmin-issues
Garmin watches have recently been gaining popularity for sites such as [GPS-Speedsurfing](https://www.gps-speedsurfing.com/) and [Speedsurf.app](https://speedsurf.app/).

This repo describes a number of issues / bugs relating to the current watches, and some desirable enhancements.

All of the items have been recorded as Github "issues" but this page attempts to list them in a logical order.

Anything pertaining to accurate GNSS data is deemed to be priority 1, and everything else is priority 2.
